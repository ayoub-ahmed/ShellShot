==================================================
PROJECT
==================================================

Project name:
ShellShot

Purpose:
ShellShot is an AI-powered sea turtle image classification application.

The user uploads an image of a turtle or an environment/image containing no turtle.

The backend sends the image through a trained deep-learning model and returns:

- Predicted class
- Confidence
- Probability for every class

Supported classes:

1. Green Turtle
2. Leatherback Turtle
3. Loggerhead Turtle
4. Unknown

"Unknown" represents images where no supported turtle species is detected, such as beaches, rocks, roads, other animals, etc.

The application should be suitable for a university AI capstone presentation.

==================================================
IMPORTANT MODEL PREPROCESSING
==================================================

The current MobileNetV2 and ResNet50 models were trained with preprocessing INSIDE the Keras model.

For example, the MobileNetV2 model contains:

tf.keras.applications.mobilenet_v2.preprocess_input

inside the model.

Therefore:

DO NOT preprocess the image twice.

The backend should:

1. Receive the uploaded image.
2. Convert it to RGB.
3. Resize it consistently to 224x224 using resize-with-pad.
4. Add the batch dimension.
5. Send the image to the Keras model.
6. Let the model perform its internal preprocessing.

Do NOT call:

mobilenet_v2.preprocess_input()

outside the model if the saved model already contains it.

The same principle applies to the ResNet model if its preprocessing layer is included in the saved model.

Create model-specific preprocessing configuration so EfficientNet can have its own preprocessing if necessary.
